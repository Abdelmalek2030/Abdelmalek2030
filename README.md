# Abdelmalek

**Systems & Developer Tooling Engineer**  
Focused on low-overhead background daemon systems, zero-dependency CLI utilities, and developer productivity tooling across Linux and cloud environments.

---

## 🛠️ Core Engineering Principles

- **Minimal Surface Area & Zero Bloat**: Prioritizing zero-dependency or strictly audited architectures to reduce supply-chain risk and binary sizes.
- **Unix Philosophy**: Small, composable tools that accept standard inputs, emit clean outputs, and integrate seamlessly into terminal pipelines.
- **Resource Predictability**: Safe concurrency, deterministic memory footprints, and daemon stability for continuous local development.

---

## 🚀 Featured Open Source Tooling

- **[devtools-hub](https://github.com/Abdelmalek2030/devtools-hub)**: POSIX-compliant shell scripts and developer utility libraries engineered with XDG Base Directory specification compliance.
- **[docker-prune-daemon](https://github.com/Abdelmalek2030/docker-prune-daemon)**: Lightweight background daemon written in Go designed for automated disk space reclaim, dangling image cleanup, and production systemd service management.
- **[env-vault-cli](https://github.com/Abdelmalek2030/env-vault-cli)**: Zero-dependency secure CLI utility built with native Node.js crypto modules for enterprise-grade AES-256-GCM environment file encryption and synchronization.
- **[env-vault-action](https://github.com/Abdelmalek2030/env-vault-action)**: Official GitHub Action companion for secure in-memory decryption and direct injection of `.env.vault` secrets into `$GITHUB_ENV` with automated CI log masking.
